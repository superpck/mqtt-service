ต้องการทำ MQTT service server โดยไม่ต้องติดตั้ง Broker 


1.ใช้ package ของ node อย่างเดียว
2.ใช้ Typescript, dayjs, knex, jsonwebtoken
3.ขั้นตอน
  3.1 request subscribe ด้วย code (headers jwt)
  3.2 ตรวจสอบ code ใน admin.access_code (mysql) code, uid, hospcode, date, expire, isactive
  3.3 subscribe id บันทึกลงใน admin.mqtt_subscribe จำแนกตาม uid, hospcode
4.ฐานข้อมูลสำหรับเก็บข้อมูล mqtt อยู่ใน admin.mqtt_event
